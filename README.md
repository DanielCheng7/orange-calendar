# 🍊 日历提醒 - 微信小程序

一个功能丰富的微信日历提醒小程序，支持提醒管理、标签分类、每日备注、重复提醒和暗黑模式。

## 功能

- **月视图日历** — 按月份浏览，有提醒的日期显示小圆点标记
- **提醒管理** — 新建、编辑、删除提醒，支持完成状态切换
- **标签分类** — 自定义标签，支持颜色标记，按标签筛选提醒
- **每日备注** — 每天可记录备注内容，自动保存到云端
- **重复提醒** — 支持每日、每周、每月、每年重复
- **批量操作** — 选择模式，批量删除提醒
- **暗黑模式** — 跟随系统自动切换深色/浅色主题

## 技术栈

- **框架** — 微信原生小程序 + 云开发
- **基础库** — 3.6.0
- **数据库** — 微信云数据库（reminders / tags / notes）
- **云函数** — getOpenid / pushReminder（定时推送提醒）
- **设计** — CSS Custom Properties 设计令牌系统，支持主题切换

## 项目结构

```
miniprogram/
├── app.js / app.json / app.wxss    # 应用入口与全局样式
├── pages/
│   ├── calendar/                    # 主日历页面（月视图 + 提醒预览 + 每日备注）
│   ├── day/                         # 日视图页面（当天完整提醒列表）
│   ├── editor/                      # 提醒编辑页面
│   ├── settings/                    # 设置页面
│   └── tags/                        # 标签管理页面
├── components/
│   ├── calendar-grid/               # 月日历网格组件
│   └── reminder-card/               # 提醒卡片组件
└── utils/
    ├── cloud.js                     # 云数据库封装
    ├── date.js                      # 日期工具函数
    └── repeat.js                    # 重复提醒逻辑
cloudfunctions/
├── getOpenid/                       # 获取用户 OpenID
└── pushReminder/                    # 定时推送提醒通知
```

## 开发

使用微信开发者工具打开项目根目录，填入自己的 `appid` 即可预览。

首次使用需在云开发控制台创建以下集合：
- `reminders` — 提醒数据
- `tags` — 标签数据
- `notes` — 每日备注数据
