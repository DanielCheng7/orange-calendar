# 日历提醒微信小程序 — 设计文档

**日期**: 2026-05-16
**状态**: 已批准

---

## 概述

个人日程管理微信小程序，基于微信云开发，以月视图为核心提供提醒事项的创建、管理、分享和推送功能。

## 技术选型

- **前端**: 微信原生开发（WXML + WXSS + JS/TS）
- **后端**: 微信云开发（CloudBase）
  - 云数据库：存储提醒和标签数据
  - 云函数：定时检查并推送订阅消息
- **提醒**: 微信服务通知（订阅消息）
- **分享**: 微信原生转发接口

## 架构

```
视图层（4个页面）
  ├── 月视图首页（日历网格）
  ├── 日视图（提醒列表）
  ├── 添加/编辑提醒
  └── 设置
        │
逻辑层
  ├── 提醒服务（CRUD + 重复计算）
  ├── 订阅消息服务
  ├── 分享逻辑
  └── 缓存管理
        │
云开发层
  ├── 云数据库（reminders + tags）
  ├── 云函数（消息推送）
  └── 云存储
```

## 页面设计

### 1. 月视图首页
- 7×6 日历网格，左右滑动切换月份
- 有提醒的日期显示红点标记
- 点击日期跳转到日视图
- 顶部显示当前年月，左右箭头切换

### 2. 日视图（提醒列表）
- 显示选中日期的所有提醒
- 每条提醒：左侧色条（标签颜色）+ 标题 + 标签名 + 时间 + 完成复选框
- 顶部 + 按钮添加新提醒
- 左滑/长按：删除 / 分享
- 已完成事项显示为勾选状态，视觉置灰

### 3. 添加/编辑提醒
- 表单字段：标题（必填）、日期（必填，默认今日）、时间（可选）、重复规则（不重复/每天/每周/每月/每年）、标签（单选）、备注（可选）
- 保存后自动返回上一页

### 4. 设置
- 订阅消息管理：跳转授权设置
- 标签管理：增删改标签名称和颜色
- 主题切换：浅色/深色
- 关于：版本号

## 数据模型

### reminders 集合

| 字段 | 类型 | 说明 |
|------|------|------|
| `_id` | string | 自动 |
| `_openid` | string | 微信用户标识 |
| `title` | string | 提醒标题 |
| `date` | string | 日期 YYYY-MM-DD |
| `time` | string | 时间 HH:mm（可选） |
| `tag` | string | 标签ID |
| `priority` | number | 优先级 1-3 |
| `repeat` | string | none/daily/weekly/monthly/yearly |
| `note` | string | 备注（可选） |
| `done` | bool | 是否完成 |
| `doneDates` | string[] | 已完成的日期列表（用于重复提醒） |
| `createdAt` | timestamp | 创建时间 |
| `updatedAt` | timestamp | 更新时间 |

### tags 集合

| 字段 | 类型 | 说明 |
|------|------|------|
| `_id` | string | 自动 |
| `_openid` | string | 微信用户标识 |
| `name` | string | 标签名 |
| `color` | string | 颜色 hex 值 |
| `order` | number | 排序 |

## 核心交互

### 订阅消息
1. 用户创建提醒后弹出订阅授权
2. 授权后云函数定时检查待推送提醒
3. 到时间发送微信服务通知
4. 用户未授权则仅小程序内弹窗提醒
5. 微信限制：一次性订阅，每次需用户确认

### 分享
1. 日视图左滑/长按提醒 → 选择分享
2. 调用微信转发接口生成卡片
3. 好友点击卡片可预览提醒内容（只读，不可编辑）

### 重复提醒
1. 存储原始日期 + repeat 规则
2. 查询时动态计算：对于 daily/weekly/monthly/yearly，根据规则展开到指定月份
3. 完成：仅标记 `doneDates` 中当天，不影响后续重复
4. 删除：可选择"删除本次"或"删除全部"
